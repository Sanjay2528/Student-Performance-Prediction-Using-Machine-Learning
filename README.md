# Student Performance Predictor

This project predicts whether a student will pass or fail their exams based on their daily study habits. It uses a machine learning classification model to analyze student data and provide immediate predictions.

## 🚀 Technologies Used
* **Python** — Core programming language
* **Scikit-learn** — Machine learning modeling and evaluation
* **Pandas** — Data manipulation and analysis

## ⚙️ How to Run
Follow these steps to set up and run the project locally:

1. **Install Python**: Ensure you have Python 3.x installed on your system.
2. **Install libraries**: Run the following command in your terminal to install the required dependencies:
   ```bash
   pip install pandas scikit-learn
   ```
3. **Run the application**: Execute the main script:
   ```bash
   python main.py
   ```

## 📊 Model Details

### Input Features
The model evaluates the following student habits:
* **Study hours** — Average hours spent studying per day
* **Attendance** — Percentage of classes attended
* **Sleep hours** — Average hours of sleep per night

### Output
The system predicts one of two outcomes:
* `0` = **Fail**
* `1` = **Pass**
